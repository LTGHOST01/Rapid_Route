# RapidRoute frontend

React + Vite dispatcher console. See the repository [README](../README.md) for setup, and [GROK_FRONTEND_BRIEF.md](../docs/GROK_FRONTEND_BRIEF.md) for design rules.

`VITE_API_BASE_URL` must point at the Express API (`/api`). `VITE_GOOGLE_MAPS_BROWSER_KEY` is optional; without it the map is a labelled demo schematic.
